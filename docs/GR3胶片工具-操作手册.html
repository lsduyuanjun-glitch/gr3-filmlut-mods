GR III 胶片滤镜工具

操作手册 · 适用于 macOS 版 v1.5.2 · 适配理光 GR III / GR IIIx 官方固件 2.39

本工具把「胶片滤镜」烧录进相机固件，刷机后相机直出 JPG 就自带胶片色彩和颗粒，无需手机、无需后期、也无需机内逐项调整。本手册面向把工具发给的最终用户，照着做即可。

一句话流程：打开工具 → 选好 6 个槽位装什么胶片、每槽颗粒强弱 → 点「生成固件」→ 改名 fwdc239b.bin 放 SD 卡根目录 → 相机关机、按住 MENU 开机刷入。

一、使用前准备

  • 电脑：macOS（Intel 或 Apple 芯片均可，安装包已含通用二进制）。
  • 相机固件：请确保相机为官方 2.39 版本（设置 → 固件版本可查）。本工具基于 2.39 修改，其它版本不保证可用。
  • 备份（强烈建议）：先在工具「固件」区下载一份官方 .bin 存好。万一想恢复，用同一份官方固件刷回即可，不会变砖。
  • SD 卡：一张能插进相机、可在电脑读写的卡，用于传递固件文件。

二、三步上手

1
启动工具
双击 GR3胶片工具.app，会自动打开浏览器窗口。右上角有一个版本角标，显示 v1.5.2 即表示是最新版（若显示旧版本号，先重启电脑再开，或看第六节的「端口问题」）。
2
配置槽位与颗粒
界面分三栏：左栏胶片库（所有可用胶片）、中栏槽位详情（选中某个槽位后，给它装胶片 + 选颗粒）、右栏说明 / 解锁 / 新建。
默认 6 个槽位已装好：5207（免费）、Portra 400、Ektar 100、Kodak 5219，外加 2 个空槽位可放你自己的胶片。
3
生成并刷机
配置满意后，点「生成固件」，工具会产出 gr3_film_mods_custom.bin。下载它，改名为 fwdc239b.bin，放到 SD 卡根目录。相机插卡、关机，按住 MENU 键不松，再开机，按屏幕提示刷入即可。

三、功能详解

3.1 胶片槽位（6 个）

相机菜单末尾会追加 6 个「新增影像控制项」槽位（位于官方「高对比黑白」之后）。每个槽位决定相机直出时套用哪款胶片。

槽位默认胶片说明
槽位 1Kodak 5207（免费）开箱即用，无需解锁
槽位 2Portra 400需解锁码（见 3.4）
槽位 3Ektar 100需解锁码
槽位 4Kodak 5219需解锁码
槽位 5、6空可上传你自己的 CUBE / XMP 自制胶片

在中栏选中某槽位 → 「滤镜胶卷」下拉里挑一款胶片即可换装。同一款胶片被两个槽位占用时会自动交换位置。

3.2 逐槽颗粒（核心功能）

每个槽位详情里都有独立的「颗粒强度」下拉，四档：

档位效果
无颗粒干净，无叠加
Low（弱）极细颗粒，几乎不可见，适合 Portra 400 / Ektar 100 这类细颗粒片
Mid（中）中等颗粒，接近 5207 日光片质感（默认档）
High（强）粗颗粒，接近 5219 钨丝灯片 / 迫冲的感觉
颗粒是「烧进固件」的：选好后随固件一起烘焙，相机直出 JPG 就带颗粒，换滤镜、关机重开都不会丢。颗粒只在 JPEG 直出上生效，RAW 文件不受影响（RAW 可回放做影像控制）。

3.3 自定义胶片与图标

  • 新建胶片：右栏「新建胶片」上传你的 .CUBE 或 .XMP，填英文名（机内只支持英文/数字），即可生成一款自制胶片，放进槽位 5、6。
  • 自定义图标：在左栏胶片库里，点某款自制胶片的「图标」按钮，上传一张图片作为机内图标（约 40×40）。重新生成并刷机后生效。
  • 改名 / 删除：左栏同名按钮可对自制胶片改名或删除（内置 4 款不可删）。

3.4 解锁付费胶片

Portra 400 / Ektar 100 / Kodak 5219 为付费款，在右栏输入你获得的解锁码即永久解锁，无需重复输入。

四、刷机与回刷

刷入自制固件

  1. 工具里点「生成固件」，下载 gr3_film_mods_custom.bin。
  2. 改名为 fwdc239b.bin（必须这个名）。
  3. 拷到 SD 卡根目录（不要放进文件夹）。
  4. 相机插入 SD 卡，关机。
  5. 按住 MENU 键不放，同时开机，屏幕出现固件更新提示，按提示确认。
  6. 刷完开机，菜单里就能看到新增的胶片槽位。

恢复到官方固件

在工具「固件」区下载官方 .bin，同样改名 fwdc239b.bin、放 SD 卡根目录，用上面的 MENU 开机法刷入即可 100% 还原官方状态。本操作可随时来回切换。

安全说明：工具修改的是固件内的影像处理参数，不涉及底层 Bootloader。保留官方 .bin 备份即可随时回刷，正常操作不会损坏相机。刷机过程请保证电量充足。

五、实拍验证

  • 刷机后，对某个已设颗粒的槽位拍一张 JPEG，放大看应能看到对应强弱的颗粒。
  • 若看不出颗粒：确认该槽位颗粒档不是「无颗粒」；确认拍的是 JPEG 而非 RAW；确认刷的是最新生成的固件。
  • 不同光线/ISO 下颗粒观感会有差异，属正常现象。

六、常见问题

Q1：打开后界面像是旧版本 / 没变化？

工具后台服务占用了固定端口（8310）。如果之前开过旧版本、又没关，新版本会自动接管；极少数情况下旧进程残留，表现为页面不更新。处理：重启电脑再开工具最稳妥；或在「活动监视器」里结束名为 GR3胶片工具 / python 的进程后重开。也可在浏览器按 Cmd+Shift+R 强制刷新。右上角版本角标能帮你确认当前到底是哪个版本。

Q2：胶片库列表里 ΔE、按钮挤在一起？

这是旧版本的界面重叠问题，v1.5.2 已修复为自动换行，空间不够时按钮会掉到下一行。请使用 v1.5.2 及以上。

Q3：颗粒不生效？

检查：① 该槽位颗粒档 ≠「无颗粒」；② 拍的是 JPEG 直出；③ 刷的是带颗粒设置的那次生成的固件；④ 角标版本正确。仍无效请把样张发回排查。

Q4：机内图标出现豆腐块 / 乱码？

机内图标与菜单只支持英文/数字，胶片名或短码含中文会导致此问题。改名只用英文/数字即可。

七、版本说明

本手册对应 v1.5.2：修复胶片库列表 ΔE 徽章与操作按钮重叠的布局问题，并保留自动接管端口、右上角实时版本角标等能力。逐槽颗粒与自定义图标功能自 v1.5.0 起提供。
