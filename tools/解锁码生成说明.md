# GR3 胶片工具 —— 解锁码生成说明（仅 Duccio 自己用，勿发给买家）

这份是**卖家操作手册**，买家看不到。讲的是：怎么给买家生成付费款解锁码。

---

## 一、原理（一句话）

解锁码 = 「版本 + 胶片 key 列表」的 **ed25519 数字签名**。

- **私钥**（`tools/private_key.pem`）只有你有，用来**生成**解锁码。
- **公钥**（已写进工具里的 `license.py`）随工具分发，用来**验证**解锁码。
- 别人拿到公钥也伪造不了码；你泄露私钥 = 任何人都能自己造码。

---

## 二、生成解锁码（3 秒）

```bash
# 解锁单款
.packenv/bin/python tools/make_code.py portra400

# 解锁多款（空格分隔）
.packenv/bin/python tools/make_code.py portra400 5219 ektar100

# 解锁全部付费款
.packenv/bin/python tools/make_code.py --all
```

输出就是给买家的解锁码，形如：

```
1:portra400-9f3a...（一长串 hex）
```

把这一整串复制发给买家即可。买家在工具页面「解锁码」框里粘贴 → 永久生效。

## 三、付费款 key 对照

| 胶片         | key         | 命令行写法                    |
| ---------- | ----------- | ------------------------ |
| Kodak 5207 | `5207`      | **免费，不需要解锁码**            |
| Portra 400 | `portra400` | `make_code.py portra400` |
| Ektar 100  | `ektar100`  | `make_code.py ektar100`  |
| Kodak 5219 | `5219`      | `make_code.py 5219`      |

---

## 四、⚠️ 三条红线（务必照做）

1. **私钥绝不能外泄**：`tools/private_key.pem` 不要上传 GitHub、不要发网盘公开链接、不要进任何会同步到云的工具包。建议复制一份到本地离线硬盘/U 盘备份。
2. **不要重复运行 `make_license_keys.py`**：每次运行都会生成新密钥对，之前发给所有买家的解锁码会**全部失效**（公钥变了）。所以密钥只生成一次，之后只跑 `make_code.py`。
3. **备份好 `private_key.pem` 再重装系统/换电脑**：私钥丢了，就无法再生成新解锁码，只能重新生成密钥并让老客户重新领码。

---

## 五、密钥文件位置

```
tools/private_key.pem     私钥（保密，别进工具包）
webtool/license.py        PUBLIC_KEY 公钥（随工具分发）
tools/make_code.py        生成解锁码的脚本
tools/make_license_keys.py 生成密钥对（只跑一次）
```

---

## 六、技术细节（可选读）

- 签名算法：Ed25519（`cryptography` 库）
- 解锁码格式：`1:<keys>-<128位hex签名>`，`keys` 是逗号分隔的胶片 key
- 校验逻辑：工具用内置公钥验签，通过后写入本地 `license.json`，永久生效、不联网、不绑机器
