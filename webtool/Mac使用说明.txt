====================================================
  GR III 胶片滤镜工具 · Mac 使用说明
====================================================

全程只需做一次「安装」，以后每次都是「双击启动 → 生成 → 刷机」三步。

----------------------------------------------------
一、准备工作（只做一次）
----------------------------------------------------

1. 装 Python（如果电脑还没有）
   - 打开 https://www.python.org/downloads/
   - 点黄色的 Download Python 按钮，下载后双击安装
   - 一路「继续」装完即可
   - 怎么确认装好了：打开「终端」App，输入 python3 --version 回车，
     出现类似 Python 3.12.x 就说明成功

2. 装依赖（本工具需要 5 个库，自动装，约 200MB，需联网）
   - 双击包里的「安装依赖.command」
   - 等它跑完，看到「依赖安装完成」就关掉

3. 下载官方固件（必须，本工具不随附官方固件）
   - 打开理光官网 GR III 固件页：
     https://www.ricoh-imaging.co.jp/english/support/digital/gr3_s.html
   - 找到 Version 2.10，下载 gr3_v210.zip
   - 解压后得到 fwdc239b.bin（约 30MB）
   - 把这个 fwdc239b.bin 拖进本包的 official_firmware 文件夹

----------------------------------------------------
二、生成固件（每次用都做）
----------------------------------------------------

1. 双击「启动工具.command」
   - 会弹出一个终端窗口，稍等 1~2 秒
   - 浏览器会自动打开 http://localhost:8310
   - 如果没自动打开，手动在浏览器输入这个地址即可

2. 在网页里配胶片
   - 选择你要的胶片预设（Portra 400 / 5219 / 5207 / Clean / BW 等）
   - 颗粒在相机菜单里调（Off / Low / Mid / High），网页不用选
   - 点「生成固件」，等进度走完（约半分钟到一分钟）

3. 下载固件
   - 生成完成后点「下载」，得到一个 .bin 文件

----------------------------------------------------
三、刷入相机
----------------------------------------------------

1. 准备一张 SD 卡（用相机格式化过的最好）
2. 把刚下载的 .bin 文件复制到 SD 卡根目录（不要放进任何子文件夹）
3. 相机装好满电电池，关机
4. 插入 SD 卡，盖好卡盖
5. 按住【Menu】键不放，同时按电源键开机
6. 屏幕出现「更新相机固件」，用方向键选「执行」→ 按【OK】
7. 等进度条走完，显示「更新完成」后关机
8. 取出 SD 卡，在相机里格式化一下（清掉 .bin 文件，避免下次误触发）

----------------------------------------------------
⚠️ 重要提醒
----------------------------------------------------

- 更新过程中绝对不要关机、不要拔电池、不要拔卡，
  一旦中断相机可能变砖，且官方不保修。
- 刷的是第三方修改固件，风险自担。刷前建议先备份好官方固件。
- 本工具只能用于 GR III 的 2.10 固件；GR IIIx / GR IV 不适用。

----------------------------------------------------
常见问题
----------------------------------------------------

Q：双击「启动工具.command」提示「无法打开」
A：右键点它 → 打开 → 再点一次「打开」。这是 macOS 对下载脚本的安全拦截，第一次放行即可。

Q：网页打不开 / 显示「未就绪」
A：先确认官方固件已放进 official_firmware 文件夹，再刷新网页。

Q：提示「固件不匹配」
A：说明你放的固件不是 GR III 2.10 版（SHA 校验不过），请重新下载官方 fwdc239b.bin。

Q：终端窗口关了工具还开着吗？
A：关掉那个终端窗口，工具就停了。每次用完直接关窗口即可。
